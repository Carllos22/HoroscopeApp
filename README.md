# 🌌 HoroscopeApp - Android Mobile Application

A native Android application built in Kotlin that demonstrates modern mobile architecture, network communications, and data parsing.

### 🛠️ Features & Technical Highlights
- **REST API Integration:** Connects to remote services to fetch dynamic daily horoscope data.
- **JSON Parsing:** Efficiently processes server responses into local application models.
- **Intent Navigation:** Handles multi-screen workflows and secure data passing between activities.
- **Clean Architecture Principles:** Separation of UI logic and network data handling.
